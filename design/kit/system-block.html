When to use it

Maintenance and the 500 page. It deliberately does not carry the App bar: on these two screens the product is not available, and showing navigation that leads nowhere is worse than showing none.

The rule, and the anti rule

Do this. One message, centred, with the wordmark above it so the person knows they are still in the right place.

Not this, use Error code instead. A page that is missing rather than broken keeps the normal frame and shows an Error code with a State block.

States

No states: this component is not interactive. Not interactive. It has no coloured instance in the sample: it is built from the rule that already existed in the flat kit, not invented here.
