When to use it

The two error pages, and nowhere else. It is decorative in the strict sense and carries aria-hidden, because the sentence below it is what a screen reader should read.

The rule, and the anti rule

Do this. Always with a State block underneath that says what happened in words and offers a way back. The number alone tells nobody anything.

Not this, use State block instead. Do not use this step of the scale anywhere else. A page heading is --text-display and a score is --text-read.
