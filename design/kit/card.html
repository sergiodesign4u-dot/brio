The empty cells, and why they are empty

No emphasis axis. A card never changes colour to mean something: the meaning is in what is inside it. That is principle 4 held at the level of a container.

When to use it

Everywhere the operator reads. The dashboard is cards, the roster is a card holding a list, the library is cards holding programs. It is the unit the content grid arranges.

The rule, and the anti rule

Do this. One subject per card. If a card needs two headings, it is two cards.

Not this, use State block instead. A card that reports a state and offers a next step is a State block, which already has a title, a sentence and an action in the right order.

States

No states: this component is not interactive. Not interactive. A card is not a link anywhere in this product, so it has no hover: if a whole card were pressable it would need a focus ring and a keyboard role, and neither exists here.
