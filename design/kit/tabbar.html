The empty cells, and why they are empty

No emphasis axis and no size axis. It exists at exactly one width, under 720px, and the App bar tabs exist at exactly the other. A control census taken at one viewport would have missed one of the two entirely, which is why every walk in this stage is taken twice.

When to use it

49 screens, on a phone. It is the operator navigation on the device the operator actually carries.

The rule, and the anti rule

Do this. Four sections at most. Beyond four the labels start truncating, and a truncated navigation label is a guess.

Not this, use App bar instead. From 720px up this component is not shown at all. The sections live in the App bar there, not in a squeezed copy of this one.

States

Same answer as the App bar tabs, so no second set of state snapshots is taken. This is the delta rule at work: a group of snapshots has to have a named difference, and there is none here.

No snapshots here, and that is the rule rather than an omission. The unit of a snapshot is a difference, not an occurrence. This component answers every state exactly as App bar does, so the answer is written in this line instead of proved again with pictures. A matrix with more snapshots than named differences is a list of occurrences, not documentation.
