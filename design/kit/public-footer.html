When to use it

Every public page. The trust line above the columns is deliberate: the last thing a visitor reads before leaving is the mechanism, not a copyright.

The rule, and the anti rule

Do this. The trust line says the mechanism in the words from voice.md. It is not a slogan and it is not a link to a policy.

Not this, use App footer instead. Inside the product this is replaced by the App footer, which is one line and two links.

States

The links are text links and answer as every other one does.

No snapshots here, and that is the rule rather than an omission. The unit of a snapshot is a difference, not an occurrence. This component answers every state exactly as App bar does, so the answer is written in this line instead of proved again with pictures. A matrix with more snapshots than named differences is a list of occurrences, not documentation.
