The empty cells, and why they are empty

No size axis: one panel width for every dialog, because a decision that needs more room than this is a screen.

When to use it

Six places: log in, upgrade, end programme, delete account, manage roster, cookie consent. They were six rows in the first inventory and are one component: same zones, same order, different words. That merge is the reason stage 08 writes one css file and one page here instead of six of each.

The rule, and the anti rule

Do this. Two answers at most, and the one that continues is solid. Name the destructive action with the verb it performs ("Delete account"), never with "Yes".

Not this, use Alert banner instead. A message that needs no decision does not need a dialog. Something that just happened is an Alert banner or a State block, and both leave the person in control of the screen.

States

No states: this component is not interactive. Not interactive as a container: the buttons inside it are Buttons. It has one coloured instance in the sample and seven in the grey product, so most of its variants wait for the roll-out.
