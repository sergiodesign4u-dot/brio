Stage 07, UI and Visual

Component kit

A screen in this product is not drawn, it is assembled from the classes below. Nothing on a screen carries a style of its own: a value written on a page is a second copy of that value, and drift starts there. Missing a detail means adding it here first, in kit.css, on this page, and in the inventory, and only then on the screen.

The values arrived here from design/_theme.css by a file move, byte for byte, so the chain from the pixel of the brand plate to the token is unbroken: plate pixel then DESIGN-artifacts.md then kit.css then, at stage 08, the token file. Nothing was re-derived.
